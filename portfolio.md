# EliteCode

An AI-powered coding platform designed to help developers practice Data Structures and Algorithms, improve problem-solving skills, and receive personalized feedback.

EliteCode provides an interactive coding environment with a Monaco-based editor, timed problem-solving sessions, AI-generated hints, code explanations, and solution feedback. It integrates authentication, user progress tracking, and administrative features into a unified platform built around the coding practice experience.

## Technologies

React, Vite, Java, Spring Boot, Spring Security, Spring Data JPA, SQL, REST APIs, JWT, OAuth 2.0, Google OAuth, GitHub OAuth, Monaco Editor, AI APIs
